# To-Do List Web App
A simple and interactive to-do list application built using React.js that allows users to manage their tasks efficiently. This project demonstrates the use of state management across components in React.

## Features
- Add new tasks.
- Delete tasks.
- Responsive design for both desktop and mobile screens.
## Technologies Used
- React.js: Library for building the user interface.
- JavaScript : For logic and functionality.
- CSS: For styling the application.
## Setup Instructions
Follow these steps to run the project locally:

### Step 1: Clone the Repository
``` bash
git clone https://github.com/YourUsername/Todo-List-App.git  
cd Todo-List-App  
```
### Step 2: Install Dependencies
```
npm install
```  
### Step 3: Start the Application
```
npm start  
```
The app will be available at http://localhost:3000.
